# getplantrace.com

The PlanTrace website: static HTML on GitHub Pages, with no analytics, no cookies and no third-party requests (system fonts, inline icon).

- `/`: home page.
- `/privacy/`: privacy policy. It says «Próximamente» until Esteban approves the text.
- `/terms/`: terms of use. It says «Próximamente» until Esteban approves the text.

The app links to `https://getplantrace.com/privacy` and `https://getplantrace.com/terms`; GitHub Pages redirects them to the folders with a trailing slash.

The icon is the app's (PlanTrace-iOS, `docs/brand/icon`, version 2).
